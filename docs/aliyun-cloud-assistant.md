# 房主不用 SSH：在云厂商网页控制台里部署 mc-p2p-lan

新手最怕的就是「进服务器敲命令」这一步。其实这一步也可以完全在网页上完成——
阿里云 / 腾讯云 / 华为云的控制台都能直接往你的服务器发一条命令执行，**不需要 SSH、不需要 root 密码**。

---

## 阿里云（ECS）

### 入口一：实例详情页（推荐，最好找）

1. 登录 [ECS 控制台](https://ecs.console.aliyun.com/)，左上角选对地域
2. 在实例列表点你的服务器 ID，进入详情页
3. 右上角 **全部操作** → 搜索并点 **发送命令**（有的新版本显示为「远程命令」）
4. 弹窗里选命令类型：**Shell**
5. 命令内容粘贴这一行：

   ```bash
   curl -fsSL https://raw.githubusercontent.com/dodolu05/mc-p2p-lan/main/server/install.sh | sudo bash
   ```

6. 点 **执行**，等 2~3 分钟，输出里就会打出「联机邀请卡」

### 入口二：云助手页面（适合固定保存）

1. ECS 控制台左侧 **运维与监控 → 云助手**
2. 右上角 **创建/执行命令**
3. 命令类型选 **Shell**，粘贴上面同一行
4. 执行用户默认就是 `root`，执行路径留空即可

### 前提条件

- 实例状态是**运行中**
- 云助手 Agent 在线（ECS 默认已装；如果显示离线，在云助手页面点「安装 Agent」）
- 超时时间建议改到 **300 秒**以上（默认 60 秒可能不够下载）

---

## 阿里云轻量应用服务器

入口叫**命令助手**：控制台 → 服务器列表 → 点实例 ID → 「命令助手」页签 → 执行命令。
同样选 Shell、粘贴同一行。

---

## 腾讯云

- 入口：控制台 → 轻量应用服务器 / 云服务器 → 实例详情 → **执行命令**（或「自动化助手」）
- 命令类型选 **Shell**，超时拉满，粘贴同一行

## 华为云

- 入口：控制台 → 弹性云服务器 ECS → 实例 → **远程登录 / 运维 > 云运维** → 执行 Shell 命令

---

## 部署完还要做一件事（不能忘）

网页部署只是把服务装好、跑起来了。**云厂商的安全组（防火墙）脚本改不了**，必须你手动去放行：

控制台 → 安全组 / 防火墙 → 添加规则：

| 协议 | 端口 | 说明 |
|---|---|---|
| TCP + UDP | 11020 | EasyTier 节点，**不放朋友一定连不上** |
| TCP | 7000 | frps 兜底 |
| TCP | 25565 等 | frp 映射出去的游戏端口，按需 |

放行完，把控制台输出里的**联机邀请卡**（网络名 / 密钥 / 接入地址）发给朋友，
让他们照 [GUIDE_FOR_PLAYERS.md](../GUIDE_FOR_PLAYERS.md) 填三个框就能进。

## 常见情况

| 现象 | 处理 |
|---|---|
| 命令助手显示 Agent 离线 | 在云助手页面点「安装 Agent」，装完重试；或改用 SSH 方式 |
| 执行超时/没输出 | 超时时间调到 600 秒；输出可能被截断，可改看 `/opt/mc-p2p-lan/connect.txt`（用网页自带的「发送文件/查看文件」或 VNC 登录看） |
| 想重装 | 重新发一次同一条命令即可（脚本幂等）；卸载是把命令换成 `curl -fsSL .../server/install.sh | sudo bash -s -- --uninstall`，再发一次 |
| 想看运行状态 | 服务器 → 远程登录（网页版 VNC）→ 执行 `systemctl status mc-p2p-lan-easytier` |
